# Schoolive Modern Website

The Schoolive website.

## Stack

- Astro
- TypeScript
- UnoCSS

## Routes

| Locale                              | Route     |
| ----------------------------------- | --------- |
| English                             | `/`       |
| Simplified Chinese                  | `/zh-CN/` |
| Hong Kong/Macau Traditional Chinese | `/zh-HK/` |
| Taiwan Traditional Chinese          | `/zh-TW/` |

## Install

```bash
npm install
```

## Development

```bash
npm run dev
```

## Validation

```bash
npm run format:check
npm run lint
npm run check
npm run test
npm run build
```

## Preview production output

```bash
npm run preview
```
